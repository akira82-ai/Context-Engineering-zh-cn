#### 摘要



一个用于实现自我验证流程的模板，通过结构化的检查机制来发现错误、验证结果并提高整体可靠性。

#### 背景与应用

当准确性至关重要，并且您希望在推理过程中构建显式的验证步骤时，请使用此模板。验证循环通过鼓励在最终确定结果前，系统性地检查假设、计算和结论，从而减少错误。

**此模板非常适用于：**

* 错误可能导致高昂代价的高风险任务

* 复杂的计算或逻辑推理链

* 容易出现常见推理谬误的情况

* 严谨性比速度更重要的场景

* 任何结果的可验证性非常重要的任务

***

#### 模板结构



```markdown
# 任务：{{任务描述}}

## 方法
使用验证循环完成此任务：

1.  初始解决方案
    - {{solution_approach}}    
    - 得出你的初步答案。

2.  验证过程   
 - 检查假设
 - 验证计算/逻辑
 - 测试边界情况
 - 考虑替代方案

3.  错误修正
  - 识别在验证过程中发现的任何问题。
  - 进行必要的修正。

4.  最终答案
   - 给出你经过验证的解决方案。
   - 注明任何不确定性或局限性。

## 预期输出
展示你的完整过程，包括初始解决方案、验证步骤、任何修正以及最终经过验证的答案。
```

***

#### 参数



* **`{{task_description}}`**: 需要完成的任务的清晰描述。

* **`{{solution_approach}}`**: 用于得出初始解决方案的方法（例如，“使用代数方程”）。

* **`{{assumption_verification}}`**: 如何验证假设（例如，“确认所有变量都得到正确解读”）。

* **`{{process_verification}}`**: 如何检查计算或逻辑（例如，“使用不同方法重新计算”）。

* **`{{edge_case_verification}}`**: 需要检查的特定边界情况（例如，“用边界值进行测试”）。

* **`{{alternative_verification}}`**: 用于验证结果的替代方法（例如，“使用不同的技术求解”）。

#### 示例



##### 示例 1：数学问题验证



```markdown
# 任务：计算一笔 $10,000 美元的投资，在年利率为 5%、每月复利一次的情况下，10 年后的未来价值。

## 方法
使用验证循环完成此任务：

1.  初始解决方案  
    - 使用复利公式：P(1 + r/n)^(nt)
    - 用给定值计算结果。

2.  验证过程    
    - 检查假设：确认该公式适用于此问题。
    - 验证计算：逐步重新计算，检查每个算术运算。
    - 测试边界情况：计算 1 年的情况，确认其增长符合预期。
    - 考虑替代方案：使用连续复利公式 FV = P * e^(rt) 进行交叉验证。

3.  错误修正
    - 识别两种计算方法之间的任何差异。
    - 检查常见错误（如小数点错误、指数错误）。
    - 如果需要，进行修正。

4.  最终答案    
    - 给出经过验证的未来价值。
    - 使用适当的精度和单位表示。

## 预期输出
展示你的完整过程，包括初始解决方案、验证步骤、任何修正以及最终经过验证的答案。
```

```python
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)
```

1\.  初步审查   &#x20;

&#x20;   \* 提出具体的改进或修复建议。

### 最佳实践



* **使用与初始解决方案不同的方法进行验证**。

* **同时进行概念性和计算性验证**——既检查方法也检查执行过程。

* **预测特定任务类型下的常见错误**，并针对这些错误进行验证。

* **对于数学问题**，使用不同的公式或近似方法进行验证。

* **对于逻辑论证**，检查是否存在谬误，并用反例进行测试。

* **对于复杂任务**，在验证整体之前先分别验证各个组成部分。

* **明确记录验证步骤**——不要只说“已验证”，而要解释是如何验证的。

* 在验证中**同时考虑假阳性和假阴性**。

* **对数值问题使用数量级检查**，以发现重大错误。

* **对于关键任务**，实施多种独立的验证方法。
