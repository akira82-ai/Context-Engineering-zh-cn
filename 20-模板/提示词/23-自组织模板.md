## **摘要**

本模板旨在**促成知识、思想和模式的涌现式自组织**，不施加显式结构，而是从组成要素的交互中自然组织。

## **上下文与应用**

当您希望知识或想法**自然地组织成连贯结构**，而不是从外部强加组织时，请使用此模板。自组织利用**涌现来创建可能比显式设计更优雅、自适应且有效**的模式和结构。

本模板的理想应用场景包括：

* 复杂领域的**知识探索**。

* **预先未知最佳结构**的情况。

* 过早组织会限制可能性的**创造性过程**。

* 需要新颖框架的**复杂问题解决**。

* 涌现式洞察比可预测结果更有价值的任务。

```markdown
# 任务： {{探索任务}}

## 要素（Elements）

- {{要素_1}}
- {{要素_2}}
- {{要素_3}}
- {{要素_4}}
- {{要素_5}}
- {{要素_6}}
- {{要素_7}}
- {{要素_8}}
- {{要素_9}}
- {{要素_10}}
- {{要素_11}}
- {{要素_12}}

## 局部交互规则（Local Interaction Rules）

1. {{交互规则_1}}
2. {{交互规则_2}}
3. {{交互规则_3}}

## 流程（Process）

1. 在不施加结构的情况下检查所有要素。
2. 允许自然分组和模式涌现。
3. 识别要素之间的连接和关系。
4. 观察自然形成的结构。
5.提炼并清晰阐述涌现出的组织结构。

## 预期输出（Expected Output）

{{输出规范}}
```

## **参数（Parameters）**

* **{{探索任务}}：** 需要探索的知识领域或问题空间。

* **{{要素\_X}}：** 将进行自组织的**独立组成部分**（概念、想法、数据点等）。

* **{{交互规则\_X}}：** 要素之间应如何交互或关联的**简单规则**。

* **{{输出规范}}：** 最终输出的格式和要求。


## **示例（Examples）**



#### **示例 1：知识领域组织**

```markdown
# 任务（Task）： 探索和组织可持续农业领域

## 要素（Elements）
- 作物轮作
- 土壤微生物组
- 节水
- 综合虫害管理
- 永续农业（Permaculture）
- 都市农业
- 原住民农业知识
- 精准农业技术
- 温室系统
- 再生实践
- 食物主权
- 碳捕获
- 有机认证
- 本地食物系统
- 农林复合经营
- 种子保存

## 局部交互规则（Local Interaction Rules）
1. 思考要素如何自然地相互补充或增强。
2. 识别要素之间潜在的冲突或权衡（tradeoffs）。
3. 寻找在相似尺度或时间范围内运作的要素。

## 流程（Process）
1. 在不施加结构的情况下检查所有要素。
2. 允许自然分组和模式涌现。
3. 识别要素之间的连接和关系。
4. 观察自然形成的结构。
5. 提炼并清晰阐述涌现出的组织结构。

## 预期输出（Expected Output）
- 呈现可持续农业的涌现式组织结构，包括：
- 形成的自然集群或类别。
- 要素之间的关键关系。
- 涌现出的任何层次结构或嵌套结构。
- 连接多个领域的中心或桥接概念。
- 从单独要素中不明显的关于该领域的洞察。
```

### **变体（Variations）**



#### **最小约束自组织（Minimal Constraint Self-Organization）**



为实现最大程度的**涌现**和最小程度的**约束**：

```markdown
# 任务（Task）： {{探索任务}}

## 要素（Elements）
[列出 15-20 个要素]

## 流程（Process）
1. 考虑每个要素与其它要素的关系。
2. 允许模式自然涌现，不强行建立连接。
3. 观察在不干预的情况下形成了哪些结构。
4. 清晰阐述形成的涌现式组织。

## 预期输出（Expected Output）
{{输出规范}}
```



### **种子引导自组织（Seeded Self-Organization）**

在允许自组织的同时，提供**引导涌现**：

```markdown
# 任务（Task）： {{探索任务}}

## 要素（Elements）
[列出要素]

## 组织种子（Organizational Seeds）
- {{种子概念_1}}：一个潜在的组织原则
- {{种子概念_2}}：另一个潜在的组织原则
- {{种子概念_3}}：第三个潜在的组织原则

## 流程（Process）
1. 思考要素如何围绕这些种子进行组织。
2. 允许要素在种子之间迁移或形成新的集群。
3. 让最终结构涌现，而不是强迫要素进入种子。
4. 提炼涌现出的组织结构。

## 预期输出（Expected Output）
{{输出规范}}
```

4. 清晰阐述多尺度组织结构。

**最佳实践（Best Practices）**



* 提供**多样化的要素**，覆盖该领域的不同方面。

* 保持**交互规则简单**——复杂性应从交互中涌现，而非规则本身。

* 纳入比表面类别更多的要素，以便实现一些出人意料的分组方式。

* 在呈现要素时，不使用**预先分类**。

* **混合不同类型的要素**（概念、方法、工具、原则、示例）。

* 允许**异常值**——并非所有要素都需要整齐地融入涌现结构。

* 对**过程保持耐心**——真正的自组织可能需要时间来发展。

* 寻找**涌现特性**，即个体要素中不存在的特性。

* 关注**意外的分组**——它们通常能带来新颖的洞察。

* **记录涌现过程**——过程本身揭示的信息往往与目的地一样多。

* 对**多种有效的组织结构保持开放**——复杂领域可能有几种有用的结构。
