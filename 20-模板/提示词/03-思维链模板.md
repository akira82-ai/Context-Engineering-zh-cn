## 摘要

一个用于指导 AI 系统通过明确分步推理过程的模板，提高复杂任务的准确性和透明度。

## 背景与应用

当任务需要仔细推理，或者得出结论的过程与结论本身同等重要时，请使用此模板。通过将复杂的思考分解为明确的步骤，思维链提示可以提高准确性，实现验证，并使推理过程透明化。

此模板适用于：

* 复杂问题解决任务

* 需要逻辑推理的情况

* 多步计算或分析

* 解释"为什么"很重要任务

* 减少难题中的错误

## 模板结构

```plain&#x20;text
# 任务：{{任务描述}}

## 方法
按以下步骤逐步思考：

1. {{第一步推理}}
2. {{第二步推理}}
3. {{根据需要添加的其他步骤}}
4. 根据此推理得出结论。

## 预期输出
提供完整的推理过程，然后给出最终答案。
```

## 参数

* `{{任务描述}}` : 清晰描述要解决的问题或需要回答的问题

* `{{第一步推理}}` : 推理过程的初始步骤（例如，“识别关键变量”）

* `{{第二步推理}}` : 下一个逻辑步骤（例如，“确定变量之间的关系”）

* `{{根据需要添加的其他步骤}}` : 进一步指导完整推理的步骤

## 示例

### 示例 1：数学问题解决

```plain&#x20;text
# 任务：解决以下应用题

一家商店的笔记本售价为每本4美元，钢笔售价为每支2美元。艾玛买了一些笔记本，钢笔的数量是笔记本的两倍。如果她总共花了24美元，那么她买了多少本笔记本？

## 解题思路
按以下步骤逐步思考：

1. 为我们要求解的未知量定义变量
2. 根据给定信息列出方程
3. 解方程求出未知值
4. 验证答案是否符合原始条件

## 预期输出
给出完整的推理过程，然后给出最终答案。
```

### 示例 2：伦理决策分析

```plain&#x20;text
# 任务：分析以下情景的伦理影响

一家制药公司研发出一种有望治疗罕见疾病的药物。临床试验显示，该药物的有效率为70%，但也揭示出15%的患者可能会出现严重的副作用。公司需要决定是否将这种药物推向市场。

## 方法
按以下步骤逐步思考：

1. 确定此情景中的关键利益相关者
2. 分析推出该药物的潜在益处
3. 考虑其中涉及的潜在危害和风险
4. 评估可能存在的替代方案
5. 平衡相互冲突的伦理原则（行善、不伤害、自主、公正）
6. 制定一个有细微差别的建议，并提出潜在的保障措施或条件

## 预期输出
提供完整的推理过程，然后给出最终建议。
```

## 变体

### 自我提示思维链

为了鼓励 AI 发展自己的推理步骤：

```plain&#x20;text
# 任务：{{任务描述}}

## 方法
- 首先，将这个问题分解为逻辑步骤
- 系统地处理每个步骤
- 展示完整的推理过程
- 然后再给出最终答案

## 预期输出
逐步推理，随后得出结论。
```

### 引导式问题分解

对于需要更结构化指导的高度复杂问题：

```plain&#x20;text
# 任务：{{任务描述}}

## 问题分解
1. 子问题 1：{{子问题描述}}
   - 考虑：{{相关因素 1}}
   - 考虑：{{相关因素 2}}

2. 子问题 2：{{子问题描述}}
   - 考虑：{{相关因素 1}}
   - 考虑：{{相关因素 2}}

3. 整合：结合子问题的分析结果

## 预期输出
每个子问题的分析、见解的整合以及最终结论。
```

## 最佳实践

* 将推理步骤与问题类型匹配 - 不同的問題需要不同的推理方法

* 明确推理过程 - 清晰地阐述每一步应该进行怎样的思考

* 包含验证步骤 - 添加检查工作或验证结论的步骤

* 对于数学问题，包含检查单位和数量级的步骤

* 对于伦理或主观分析，包含考虑多个视角的步骤

* 不要跳过步骤 - 将推理分解为更小的步骤可以提高准确性

* 使用 3-7 步来解决大多数问题 - 步骤太少缺乏指导，太多则令人不知所措

* 鼓励元认知 - 包括提示反思推理过程的步骤

* 对于复杂问题，考虑在集成之前将其分解为子问题
