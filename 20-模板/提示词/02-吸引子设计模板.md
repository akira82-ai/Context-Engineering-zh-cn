## 摘要

一个用于创建语义吸引子的模板，引导 AI 推理朝向特定的概念框架、方法或结果，而无需明确指令。

## 背景与应用

当你希望通过在语义空间中创建“吸引子”来微妙地引导 AI 推理朝向特定类型的响应时，请使用此模板——这些吸引子是概念重力井，自然地将思考引向某些方向。与直接指令不同，吸引子通过建立 AI 自然继续或完成的模式来发挥作用。

这个模板非常适合：

* 鼓励特定的思维模式或框架，而无需明确要求

* 创建微妙引导，使其感觉自然而非强迫

* 建立推理的“重心”，以便围绕其旋转

* 在引导推理的同时保持灵活性和创造性

* 在不指定具体结果的情况下产生影响

## 模板结构

```plain&#x20;text
# 任务：{{任务描述}}

## 上下文
{{神经网络上下文}}

## 概念框架
*以下概念可能值得考虑：*

{{主要吸引因素概念1}}：
- {{支持要素1a}}
- {{支持要素1b}}
- {{支持要素1c}}

{{主要吸引因素概念2}}：
- {{支持要素2a}}
- {{支持要素2b}}
- {{支持要素2c}}

{{共振概念}}：
- {{共振要素a}}
- {{共振要素b}}

## 方法
在分析中考虑上述概念，并根据任务的需要适当地融入这些概念。

## 预期输出
{{输出规范}}
```

## 参数

* `{{task_description}}` : 未明确提及吸引子概念的作业描述

* `{{neutral_context}}` : 建立背景信息，提供上下文，但避免偏向吸引子

* `{{primary_attractor_concept_X}}` : 想要作为语义吸引子起作用的主要概念

* `{{supporting_element_X}}` : 确认和强化吸引子概念的因素

* `{{resonant_concept}}` : 一个与主要吸引子产生共鸣并增强其效应的概念

* `{{output_specifications}}` : 输出的格式和结构规范

## 示例

### 示例 1：系统思维吸引子

```markdown
# 任务：分析发展中城市面临的城市交通挑战

## 背景
全球城市地区都在经历人口增长，给现有的交通基础设施带来了压力。许多城市都在寻求解决交通出行挑战的办法。

## 概念框架
*以下概念可能值得考虑：*

相互关联性：
- 交通与土地利用之间的关系
- 交通选择对环境系统的影响
- 交通出行与经济机会之间的联系

反馈循环：
- 基础设施投资如何塑造发展模式
- 交通拥堵与行为适应之间的关系
- 影响未来交通选择的环境影响

涌现性：
- 个人交通决策产生的模式
- 交通政策的意外后果
- 城市交通的自组织方面

## 方法
在分析中考虑上述概念，并根据任务需要适当纳入这些概念。

## 预期产出
对城市交通挑战进行全面分析，确定关键问题，探究潜在动态，并提出可能的解决办法。包括短期和长期视角。
```

### 示例 2：创意创新吸引子

```markdown
# 任务：为智能家居恒温器提出产品改进建议

## 背景
智能恒温器在家庭中越来越普遍，它允许进行温度编程、远程控制，并具备一定的学习能力。公司正寻求开发下一代产品。

## 概念框架
*以下概念可能值得考虑：*

突破边界：
- 将功能扩展到传统温度控制之外
- 与意想不到的系统或服务集成
- 挑战对恒温器应有功能的固有认知

重新组合：
- 融合不同产品类别的功能
- 对现有技术进行新颖组合
- 对熟悉的功能进行意想不到的应用

以用户为中心的惊喜：
- 具备能预见用户未知需求的功能
- 提供超出预期的愉悦交互体验
- 带来变革性体验，而非渐进式改进

## 方法
在分析中考虑上述概念，并根据任务需要适当地融入这些概念。

## 预期输出
列出5 - 7条创新的产品改进建议，每条建议都包含简要描述、潜在用户益处和实施考虑因素。重点关注独特的想法，而非显而易见的渐进式改进。
```

## 变体

### 多吸引子场域

用于创建具有不同强度的多个吸引子：

```plain&#x20;text
# 任务：{{任务描述}}

## 上下文
{{神经网络背景}}

## 概念框架
*以下概念可能相关，需考虑（无特定顺序）：*

{{主要吸引因素}} [强度：高]：
- {{支持要素}}

{{次要吸引因素}} [强度：中]：
- {{支持要素}}

{{三级吸引因素}} [强度：低]：
- {{支持要素}}

## 方法
在你的回复中考虑这些概念，并给予每个概念适当的考量。

## 预期输出
{{输出规范}}
```

### 吸引子-排斥子动力学

为创建吸引和排斥的概念力量：

```plain&#x20;text
# 任务：{{任务描述}}

## 上下文
{{神经网络上下文}}

## 概念框架
*在构思回复时，请考虑以下内容：*

相关方法：
- {{吸引子概念1}}
- {{吸引子概念2}}
- {{吸引子概念3}}

应避免的方法：
- {{排斥子概念1}}
- {{排斥子概念2}}

## 方法
在构思回复时，借鉴相关方法，同时避免应避免方法的局限性。

## 预期输出
{{输出规范}}
```

### 共鸣场域吸引子

为创建相互强化的概念，彼此放大：

```plain&#x20;text
# 任务：{{任务描述}}

## 上下文
{{神经网络上下文}}

## 概念框架
*以下相互关联的概念可能相关：*

{{概念1}} ↔ {{概念2}}：
- {{概念1}}如何影响{{概念2}}
- {{概念2}}如何强化{{概念1}}

{{概念2}} ↔ {{概念3}}：
- {{概念2}}塑造{{概念3}}的方式
- {{概念3}}增强{{概念2}}的方式

{{概念3}} ↔ {{概念1}}：
- {{概念3}}与{{概念1}}之间的关系
- 相互放大效应

## 方法
在分析中考虑这些共鸣关系。

## 预期输出
{{输出规范}}
```

## 最佳实践

* 要微妙而非强硬 - 吸引子效果最佳时，感觉像是自然的考虑，而非强制的需求

* 创建连贯的吸引子场 - 使用自然互补的概念

* 平衡具体性和开放性 - 太模糊不会产生足够的吸引力，太具体则变得具有规定性

* 使用辅助元素来明确吸引子的定义 - 帮助明确吸引子概念所包含的范围

* 将吸引子定位为“需要考虑的概念”而非要求 - 既保持灵活性，又营造微妙的重力

* 使用熟悉的概念作为桥梁连接到不熟悉的概念 - 帮助创建通往新颖思维的路径

* 对于复杂任务，使用多个共振吸引子 - 构建丰富的概念领域

* 测试吸引子的强度 - 如果太弱，增强支持元素；如果太强，减少具体性

* 将吸引子与真正目标对齐——拉动应指向真正有用的方法

* 设计易于发现的吸引子——它们应感觉像洞察力而非指令
